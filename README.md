# Software-Design-Lab-Project

**Project Overview:** The project is a web-based application designed for managing the operations of a residential building or society. It is intended to replace traditional paper-based management systems with a more efficient, user-friendly digital solution. The project demonstrates the application of key concepts in web development and database management, with a focus on real-world problem-solving. It serves as a stand-alone system and can be extended for future scalability and functionality.

**Features:** 
- Authentication: Secure login/signup system for different user roles (residents, guards, admins) along with forgot password feature.
- Digital Ledger Of Society Expenses: Admin can add society expenses (e.g., utility bills, repairs, cleaning  services) in the form of financial ledger. Members can view a summarized list of monthly expenses.
- Property Management: Admin can add, update, and delete flat details. Admin can change the status of flats among vacant, on rent and booked.
- Polls: Admin can create polls with poll description and multiple options. Residents can cast their vote only once per poll. Residents cannot change their vote after submission. Both the admin and resident can see the results once the admin closes the poll.
- Notification and Alert: The system allows the admin to send notifications to residents regarding upcoming events, meetings, and community updates. The system allows the admin to send high-priority alerts to residents via email for critical updates such as maintenance work, emergencies, or important announcements.
- Visitor Management: The system allows the security guard to log the visitors with proper details like name, purpose of visit, contact number, time of arrival and departure.
- Complaints and Service Requests: Residents can file complaints and service requests which allows the admin to review it and take actions accordingly.

**Tech Stack:** 
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MySQL
